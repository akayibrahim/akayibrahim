## 🎮 Playverse

<a href="https://playverse-rose.vercel.app">
  <img src="https://raw.githubusercontent.com/akayibrahim/playverse/main/public/assets/promo/nexus.webp" width="24%" alt="NEXUS 2100"/>
  <img src="https://raw.githubusercontent.com/akayibrahim/playverse/main/public/assets/promo/longshot.webp" width="24%" alt="LONGSHOT"/>
  <img src="https://raw.githubusercontent.com/akayibrahim/playverse/main/public/assets/promo/velocity.webp" width="24%" alt="VELOCITY"/>
  <img src="https://raw.githubusercontent.com/akayibrahim/playverse/main/public/assets/promo/echo.webp" width="24%" alt="ECHO"/>
</a>

Four games set in one city, District 07. They run in any browser on desktop and mobile, with nothing to install:
a squad tactical shooter (**NEXUS 2100**), a sniper game with real ballistics (**LONGSHOT**), an anti-grav racer
(**VELOCITY**) and a time-loop assassination mystery (**ECHO**). Built with three.js, Rapier physics and
Next.js; all audio is synthesised at runtime with WebAudio.

**[▶ Play now](https://playverse-rose.vercel.app)** · [Source](https://github.com/akayibrahim/playverse)
